# Shock Stars playtest build

Draft prototype of an ICU clinical-reasoning game for resident education (septic shock from pneumonia, scenario version 0.2.0).

- Fictional patient; educational simulation only.
- Not clinical decision support and not a validated assessment.
- Draft clinical content for the clinical owner's playtest; not approved for learner use.
- The page collects nothing and makes no network requests; progress is saved only in your browser.

This repository holds only the built single-file page (index.html). Source code and documentation are kept privately.
